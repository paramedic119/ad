# GraviTrax PRO 3D

ラベンスバーガーの立体コース玩具 **GraviTrax PRO スターターセット**（PRO Starter-Set Vertical）を
モデルにした、ブラウザで動く 3D コースビルダー＆物理シミュレーターです。
モーターも電池も使わず、**重力だけ**でボールをゴールまで導きます。

インストール不要・ビルド不要。`index.html` を開くだけで遊べます。

> 個人制作のファンメイド作品です。GraviTrax および Ravensburger は Ravensburger AG の商標です。

## 設計方針：10 歳が迷わない UI

**スマホの縦持ち専用**として設計しています。UI はすべて親指の届く下側にまとめ、
画面にはいつも「つぎに何をすればいいか」が 1 行で出ます。文字は漢字を減らしたやさしい日本語です。

いちばん大きな工夫は、**この遊びの本質でない作業を全部なくすこと**です。

### ① パーツの向きを人間に考えさせない

実物の GraviTrax でも、子どもが最初につまずくのは「タイルの向きを合わせる」ところ。
このゲームではレールをつないだ瞬間に、両端のパーツの**向き（rot）と形（cfg）が自動でそろいます**
（`Model.smartRail` / `Model.fitPorts`）。カーブの「まっすぐ／ゆるく左／キュッと右」も
自動で選ばれるので、遊ぶ人は向きを一度も意識しません。

### ② 置く前に結果が見える

パーツは**カードを指でつまんで盤に運ぶ**ドラッグ&ドロップで置きます。指の下にゴーストが追従し、
どのマスのどの高さに置かれるかが離す前に分かります。置いたパーツも**つまんで動かせる**ので、
置き間違えても消してやり直す必要がありません（`Model.moveTo`）。

### ③ 高さは自動で決まり、直すときは直接つまむ

落とした瞬間、まわりのパーツから**ころがる坂（約 12 度）になる高さを自動で提案**します
（`Model.suggestLevel`）。たいていはそのままで成立します。直したいときは、選んだパーツの上に出る
**金色のとってを 3D の中で直接つまんで**上下させます。抽象的な数値スライダーはありません。

### ④ 坂が成立しているかを色で見せる

このゲームの本質は「重力で転がる坂を作れているか」なのに、それは本来目に見えません。
そこでスタート地点からコースを辿って各レールの通行方向を求め（`Model.railFlow`）、
レールを傾きで色分けします（`Model.gradeMap`）。

| 色 | 意味 |
| --- | --- |
| 灰（そのまま） | ちょうどよく転がる |
| 黄 | ゆるすぎ／急すぎ |
| 赤 | **のぼり坂**（ボールは登れない）／たいらで止まる |

高さを変えている最中もリアルタイムで色と文言が変わるので、ルールを教わらずに体で覚えられます。

### ⑤ 「どうすればいいか分からない」を作らない

レールは 2〜4 マス先までしか届きません。届く範囲に相手がいないパーツを選ぶと、
**レールが届く空きマスを水色で光らせて**「ここに置けばつながる」と示します（`Model.railSpots`）。
色で役割を分けています。

| 色 | 意味 |
| --- | --- |
| 金 | タップするとレールでつながる相手 |
| 水色 | ここにパーツを置くとつながる場所 |

### ⑥ モードをなくす

レールの接続にモード切替はありません。パーツをタップすると**つなげる相手が金色に光り**、
それをタップすればつながります。つないだ先が自動で選択されるので、タップし続ければコースが伸びていきます。

ジェスチャの意味は 1 つずつに固定してあります。

| 操作 | 意味 |
| --- | --- |
| カードをつまんで盤に運ぶ | パーツを置く |
| 置いたパーツをつまんで運ぶ | 場所を変える |
| パーツの上のとってを上下につまむ | 高さを変える |
| パーツをタップ | 選ぶ（つなげる相手が光る） |
| 光った相手をタップ | レールでつながる |
| 何もない所を 1 本指で動かす | カメラを回す |
| 2 本指でつまむ・動かす | ズーム／移動 |

### 遊び方のモード

| モード | できること |
| --- | --- |
| 🔧 つくる | 盤面にパーツを置き、高さを変え、レールでつなぐ |
| ▶ ころがす | ボールを流す。カメラが先頭のボールを自動で追いかける |
| 🏅 ちょうせん | スタートとゴールが固定された 8 つのお題を、限られたパーツで解く |

### パソコンでの操作

マウス操作は上の表と同じです。キーボードは <kbd>Q</kbd>/<kbd>E</kbd> 高さ、<kbd>R</kbd> 回転、
<kbd>T</kbd> 形状、<kbd>Delete</kbd> 削除、<kbd>Ctrl</kbd>+<kbd>Z</kbd> もどす、
<kbd>Space</kbd> スタート、<kbd>1</kbd>〜<kbd>9</kbd> パーツ選択。

### 手ざわり

- **効果音** … Web Audio ですべて合成（音声ファイルなし）。置く・つなぐ・ゴール・キャノン発射など。
- **振動** … `navigator.vibrate` による触覚フィードバック。
- **お祝い** … ゴールした瞬間に金色のパーティクルが弾ける。
- **カメラ追従** … ころがしている間、先頭のボールを自動で追いかける（自分で視点を動かすと解除）。
- UI に隠れる範囲を実測して、コースが必ず見えるところに収まるよう視点を合わせています。

## 収録パーツ（実物のセット内容に準拠）

| パーツ | 数 | はたらき |
| --- | --- | --- |
| カーブ | 28 | コースの基本。5 種類の曲がり方（ストレート／ゆるいカーブ左右／急カーブ左右） |
| クロス | 4 | 2 本のコースを交差させる |
| 振り分け | 4 | ボールが来るたびに出口を左右交互に切り替える |
| スターター | 1 | ボールの出発点。出口は 1〜3 方向 |
| ゴール | 1 | 到着地点。空中から落ちてきたボールも受け止める |
| キャッチャー | 2 | 落下してきたボールを受け皿でとらえてコースに戻す |
| フリーフォール | 1 | コースに開いた落とし穴。真下へ落とす |
| ボルテックス | 1 | すり鉢の中を渦を描いて降り、真下へ抜ける |
| マグネティックキャノン | 1 | 飛び込んだ球が磁石にくっつき、反対側の球を高速で撃ち出す（唯一の「登る」手段） |
| レール（短・中・長） | 9 / 6 / 3 | 2 / 3 / 4 マス先のパーツへ橋をかける |
| ボール | 6 | 鋼球 |
| 高さユニット | 220 | 支柱・バルコニーに相当する縦方向の材料 |

同じマスでも高さが 5 段以上はなれていればパーツを重ねて置けます。
ボルテックスの真下にキャッチャーを置く、といった PRO らしい立体コースが組めます。

## 物理モデル

ボールは 2 つの状態を行き来します。

- **path** — 溝やレールの上を転がる 1 次元運動。弧長 `s` と速度 `v` を積分する。
  斜面の加速度は転がる剛体球として `a = -(5/7)·g·sinθ`、これに転がり抵抗と空気抵抗が加わる。
  曲率半径に対して速すぎると横 G がガイドを越え、**コースアウト**して空中へ飛び出す。
- **free** — 空中の弾道運動。パーツの天面・盤面との反発、キャッチャー／ゴールの受け口判定、
  落下してきた球が溝にうまく着地したら再び path に戻る。

同じセグメント上のボールどうしは 1 次元の弾性衝突として扱われ、玉突きや渋滞も再現されます。
マグネティックキャノンは弾倉に 2 発を保持し、球が飛び込むと先頭の球を初速 46 u/s で撃ち出します。

## ファイル構成

```
gravitrax/
├── index.html          エントリポイント（import map で three を解決）
├── css/style.css       UI スタイル
├── js/
│   ├── core.js         ヘックス座標・寸法定数・弧長パラメータ化された経路 Path3
│   ├── geo.js          BufferGeometry 生成のヘルパー（六角柱・チューブ・帯・回転体）
│   ├── parts.js        パーツ定義（経路とメッシュ）とセット内容
│   ├── model.js        コースのデータモデル・在庫・アンドゥ・保存形式
│   ├── view.js         three.js のシーン／ライティング／カメラ操作／描画
│   ├── sim.js          物理シミュレーション
│   ├── challenges.js   お題 8 種とお手本
│   ├── ui.js           DOM（パレット・HUD・モーダル）
│   └── main.js         全体をつなぐコントローラ
└── vendor/             three.js r180（同梱・MIT ライセンス）
```

外部 CDN に依存しないので、オフラインでも、ファイル一式をそのまま置いたどんなサーバーでも動きます。

### ローカルで動かす

ES モジュールを使うため `file://` ではなく HTTP で開いてください。

```sh
cd gravitrax
python3 -m http.server 8000
# → http://localhost:8000/
```

## 座標系のメモ

- ヘックスは軸座標 `(q, r)`。方向 `d`(0〜5) は +X 軸から 60°×d の向きで、そこにポート（出入口）がある。
- 1 unit ≒ 実物 1.67 cm。高さの最小単位 `H = 0.3`（小さい垂直タイル）、パーツの厚みは `2H`。
- ボール半径 0.35（実物 φ12 mm 相当）、重力 `g = 588 u/s²`（= 9.8 m/s²）。
- パーツは「ローカル空間」（原点＝セル中心、y=0＝タイル底面、回転なし）で定義し、
  `localPaths()` が返す点列を描画と物理の両方で共有している。
